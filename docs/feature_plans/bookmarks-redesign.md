# Feature plan — Bookmarks redesign

**Status:** Roadmap (curiosity / far-field; UX undecided)  
**Created:** 2026-07-29  
**Related:** [SCRATCH_NOTES.md](../SCRATCH_NOTES.md) bookmarks note, [PROJECT.md](../PROJECT.md) wish list, [UX_UI_IMPROVEMENTS.md](../UX_UI_IMPROVEMENTS.md)

---

## Goal

Replace the current bookmarks panel pattern with a **dedicated timeline-like bookmarks view**: bookmark rows with `…` gaps between non-adjacent Moments; click opens the main Timeline at that Moment.

---

## Problem

Owner explicitly undecided on interaction design; current banner/panel feels odd. Feature is parked until UX is chosen — this doc captures the preferred direction from scratch notes so it isn’t lost.

---

## Proposed direction (from owner notes)

1. Bookmarks open their own list/timeline metaphor (not a screen-wide banner dump).
2. Show ellipsis gaps to communicate “not the full show.”
3. Click → main Timeline deep link with Moment selected.

**Recommendation:** spike two UI sketches in a future session; don’t implement until owner picks one.
