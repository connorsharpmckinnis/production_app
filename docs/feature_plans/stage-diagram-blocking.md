# Feature plan — Stage diagram / click-to-block

**Status:** Roadmap (curiosity / far-field; approved as eventual candidate)  
**Created:** 2026-07-29  
**Related:** [SCRATCH_NOTES.md](../SCRATCH_NOTES.md) ambitious stage diagram idea, [PHASE_14.md](../PHASE_14.md) stage-zone wishlist, Stage Write competitive boundary in [PRE_AUGUST_STP_PREP.md](../PRE_AUGUST_STP_PREP.md)

---

## Goal

Optional **visual stage map** for quickly setting entrance/exit/blocking locations by tapping a zone (e.g. downstage left), without becoming a full ground-plan product.

---

## Problem

Typing stage locations is slow; Stage Write owns rich spacing charts. We might want a **lightweight zone picker** tied to structured blocking — not seat-licensed staging diagrams.

---

## Proposed direction

- Production-level simple stage template (quadrants / named zones).
- Optional custom outline later (admin-drawn hotspots).
- Click zone → fills location field on E/E or blocking for selected character.
- Set pieces changing the “base” stage are a known hard problem — v1 ignores live set overlays.

---

## Non-goals

- Competing with Stage Write visual prompt books
- Live show calling with moving icons
- Exact scale models

---

## Recommendation

Park until after charts + packs + pilot signal. If built, keep zones enum-simple first ([DATABASE.md](../DATABASE.md) / Phase 14 wishlist).
