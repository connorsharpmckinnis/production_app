# Feature plan — AI-assisted querying

**Status:** Roadmap (curiosity / far-field; low priority)  
**Created:** 2026-07-29  
**Related:** [PROJECT.md](../PROJECT.md) long-term AI mention, Timeline as source of truth

---

## Goal

Optional natural-language questions over **one production’s Timeline data** (“When does Crean exit before the iceberg cross?”) answered from structured data — not generative rewriting of the sacred script.

---

## Posture

- Humans decide; AI suggests.
- Sacred script text is never silently modified.
- Prefer deterministic queries (filter/derive) wrapped in NL understanding over free-hallucinated blocking advice.
- No dependency on AI for MVP workflows.

---

## Non-goals

- Autowrite scripts
- Autocast
- Cloud AI requirement for core app function

---

## Recommendation

Keep parked until packs/charts/pilot prove the data model. If revisited, start with **canned question templates** that map to existing APIs, not an open chatbot.
