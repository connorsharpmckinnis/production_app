# Feature plan — Production home & saved modes

**Status:** Roadmap (curiosity / far-field; approved as eventual candidate)  
**Created:** 2026-07-29  
**Related:** [PROJECT.md](../PROJECT.md) wish list (production home, saved views), Overview vs Timeline hub, [tech-week-chart-suite.md](tech-week-chart-suite.md)

---

## Goal

Give each production a clearer **landing home** and optional **saved views / modes** (rehearsal night, tech night, actor focus) instead of always dropping into Timeline chrome.

---

## Candidates

| Idea | Notes |
| ---- | ----- |
| Production home | Links to Overview, Timeline, Rehearse, Reports, Packs |
| Saved views | Filter/search/character/Rehearse preset bundles |
| Modes | Soft layouts emphasizing different nav (tech vs rehearsal) |

---

## Recommendation

Don’t build home until nav feels crowded in a pilot. Saved views are higher leverage than decorative home pages — especially with multi-select character filter / live search still open in UX backlog.
