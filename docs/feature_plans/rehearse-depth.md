# Feature plan — Rehearse depth

**Status:** Roadmap (curiosity / far-field; approved as eventual candidate)  
**Created:** 2026-07-29  
**Related:** Phase 6 Rehearse, [PROJECT.md](../PROJECT.md) wish list (line blur — partly shipped), [director-house-notes.md](director-house-notes.md), [character-nightly-packs.md](character-nightly-packs.md)

---

## Goal

Deepen **Rehearse** as an actor practice surface so it keeps pace with Timeline/prep investment: better navigation, practice modes, and mobile comfort — without turning Rehearse into House Mode or Reports.

---

## Candidate enhancements

| Idea | Notes |
| ---- | ----- |
| Jump to next line / next cue | Faster run-throughs |
| Stronger mobile layout | Actor on couch with phone |
| Scene + character combo presets | Save “Sunday Act 2 my lines” |
| Partner mode | See cue giver’s line only |
| Audio line prompts | Far-field |
| Spaced repetition / memory | Far-field; easy to overbuild |

Line blur already exists in some form (Phase 6); don’t rebuild — extend.

---

## Non-goals

- Replacing director house notetaking
- Gamification / streaks as core product

---

## Recommendation

After actor prep packs ship, gather actor feedback from a pilot before a large Rehearse phase. Prefer 1–2 navigation wins over a mode explosion.
